# А если бы я купил биткоин?

**[vimakushin.github.io/btc-what-if](https://vimakushin.github.io/btc-what-if)**

*English version: [README.md](README.md)*

Страница, которая проверяет фантазию «вот купил бы я тогда биткоин».

Выбираешь привычную трату (кофе, сигареты, подписку или свою сумму) и видишь, во что это превратилось бы сегодня. Потом двигаешь дату начала и смотришь, как то же самое решение даёт то плюс шестьсот процентов, то минус сорок, в зависимости от одного дня.

Дело не в красивой цифре, а в ползунке: сдвинь дату на пару месяцев, и результат перевернётся. Вывод один: дело было не в уме, а в том, когда повезло начать.

## Чем это отличается от существующих калькуляторов

Калькуляторов регулярной покупки биткоина уже много, и все они сделаны биржами и сервисами покупки биткоина, которым выгодно, чтобы ответ выглядел красиво. Убыточные периоды они не показывают, потому что это било бы по их же продажам. Здесь показаны оба исхода честно, потому что эта страница ничего не продаёт.

## Откуда цены

Дневные цены BTC/USD с [blockchain.info](https://www.blockchain.info/charts/market-price), в простом JSON-файле рядом со страницей. Без обращений к чужим API из браузера, без слежки, без регистрации. Файл обновляется сам раз в сутки через GitHub Actions.
